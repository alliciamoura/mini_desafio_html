# 👩‍💻 Portfólio - Allicia Moura

## 📋 Sobre o Projeto

Este projeto consiste na criação de uma página de portfólio pessoal para apresentar informações sobre mim, minhas habilidades, projetos desenvolvidos e formas de contato.

A atividade foi desenvolvida como parte dos estudos de **Desenvolvimento de Sistemas no SENAI**, com o objetivo de praticar conceitos básicos de desenvolvimento Web.

## 🎯 Objetivo

Criar uma página Web simples e organizada contendo:

- Informações pessoais;
- Habilidades e conhecimentos;
- Projetos desenvolvidos;
- Tecnologias utilizadas;
- Formulário de contato;
- Links para navegação entre as seções.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3

## 📌 Conteúdo da Página

### Sobre Mim
Apresenta uma breve descrição sobre minha formação e os conhecimentos que estou desenvolvendo em programação.

### Minhas Habilidades
- HTML5 Semântico
- CSS3 e Responsividade
- Formulários e Validação
- Estrutura de Dados

### Meus Projetos
A página apresenta alguns projetos desenvolvidos durante os estudos:

- **Verificador de Maioridade** — HTML5, PHP e arquivo TXT
- **Itaú - Identidade Visual** — Figma
- **Portfólio - O Diário da Princesa** — HTML e Visual Studio Code

### Entre em Contato
Foi criado um formulário para que visitantes possam preencher:

- Nome
- E-mail
- Assunto
- Mensagem

## 💻 Como Executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador Web.

## 📚 Aprendizados

Com esta atividade, foi possível praticar a criação de páginas Web utilizando HTML, organização de conteúdo, criação de tabelas, listas, links, formulários e estruturação de diferentes seções de uma página.
